## Sobre

O Treinu é o projeto do Projeto Integrador IV. O desenvolvimento é organizado com metodologia ágil, em sprints, usando o **GitHub Projects** como quadro de tarefas.

## Minha contribuição

- Organização das **sprints** e das tarefas no GitHub Projects
- Definição de prioridades e acompanhamento das entregas da equipe

## Como o projeto é gerenciado

| Etapa | Ferramenta |
|---|---|
| Backlog e sprints | GitHub Projects (quadro Kanban) |
| Tarefas | Issues vinculadas ao quadro |
| Código | Branches por funcionalidade + Pull Requests |
| Revisão | Code review antes do merge na `main` |

## Status

Em desenvolvimento (2º semestre de 2026).

## Aprendizados

- Planejamento de sprints e gestão de backlog
- Colaboração em equipe com Issues, branches e Pull Requests
